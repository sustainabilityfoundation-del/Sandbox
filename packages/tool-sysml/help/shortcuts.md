kind: shortcuts
summary: Navigate without relying on dragging.
keywords: [sysml, demo]
---

| Keys | Action |
| --- | --- |
| Tab / Shift+Tab | Move focus among available controls and diagram elements. |
| Enter / Space | Select a focused diagram element or activate a button. |
| F1 | Open contextual help for the focused control or active tool. |

Use toolbar Fit and zoom controls where available for camera navigation. No additional module-specific keyboard shortcuts are registered.
