title: Getting started with Requirements
kind: guide
summary: Open the Requirements tool, find a requirement, write a new one and see it in other tools.
keywords: [getting started, first steps, introduction]
related: [requirements.requirement.create, requirements.table]
---

1. Open **Requirements** from the tool tabs (or press Ctrl+K and type "Requirements").
2. The table lists requirements from the Requirements service. If the header shows
   "API not reachable", start the backend with `npm run dev` (see [Troubleshooting](help:requirements.troubleshooting)).
3. Select a component in the product tree or in CAD: **Filter** shows only the requirements allocated
   to it. Choose **Show all** to see everything.
4. Press Enter on a row (or double-click it) to open its details.
5. Choose **Add** to write a new requirement ([Create a requirement](help:requirements.requirement.create)).
6. Select the requirement: the inspector, SysML and the product tree show the same requirement by key.

The guided tour **Create your first requirement** (Help menu → Requirements Management → Tutorials)
walks through steps 5 and 6.
