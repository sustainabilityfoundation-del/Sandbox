Choose a collection in the **Collection** list above the table, or create one with **+**. In a
collection you can add headings, add requirements, and reorder items with **Move up** / **Move down**
(no dragging needed).

A requirement can belong to several collections. Headings and order describe the document only; they do
not create relationships. Collection changes appear in other windows within about a second.
