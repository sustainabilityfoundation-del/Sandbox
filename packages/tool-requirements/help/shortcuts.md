title: Keyboard shortcuts in Requirements
kind: shortcuts
summary: Keyboard use in the Requirements tool.
keywords: [keyboard, shortcuts, keys]
---

| Keys | Action |
| --- | --- |
| Arrow keys | Move between rows |
| Enter | Open the selected requirement |
| Escape | Close the details panel or dialog |
| Tab / Shift+Tab | Move between fields and controls |
| F1 | Help for the focused control or the open tool |
| Ctrl+K | Commands and tools |

Every action is also available without a mouse or a drag gesture.
