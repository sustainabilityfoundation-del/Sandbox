Open Project Home with the **project switcher** in the header (it shows the open project's key and name).

**Projects** tab:

- **Search** matches a project's key, name and description.
- **Show** filters by record state: active (default), archived, deleted (still restorable) or all.
- **Sort** orders by recently changed, recently opened, name, key or newest.
- **Recently opened** lists the last five projects you opened.
- **Open** switches the window to that project. The window reloads, so tool views, selections, filters and
  the assistant all start fresh in the other project; nothing from the previous project is carried over.

Which project opens when you start the workspace:

1. a project named in the address (`?project=<id>`);
2. otherwise the project this browser opened last;
3. otherwise (a new browser or cleared site data) the project you opened most recently on any computer;
4. otherwise the example project.

You only see projects you are a member of. Membership and roles are the same in every module.
