| Where | Keys | Action |
| --- | --- | --- |
| Browser | Up / Down | Move between elements |
| Browser | Right / Left | Expand / collapse |
| Browser | Enter or Space | Select the element |
| Diagram | Tab / Shift+Tab | Move between nodes, ports and connections |
| Diagram | Enter or Space | Select |
| Text editor | Ctrl+Space | Show completions (Enter accepts, Escape closes) |
| Text editor | Ctrl+Z / Ctrl+Shift+Z | Undo / redo typing before Apply |
| Text editor | Tab / Shift+Tab | Leave the editor (Tab does not indent) |
| Problems lists | Enter | Select the element or place the cursor at the error |
| Dialogs | Escape | Close without changing anything |
| Anywhere | F1 | Help for the focused control |

No essential action needs a pointer, a right-click or dragging.
