title: Keyboard use
kind: shortcuts
summary: Every control is reachable by keyboard; tree rows and graph nodes open with Enter.
keywords: [keyboard, shortcuts, accessibility]
related: [conceptualize.explorer]
---
| Keys | Action |
| --- | --- |
| Tab / Shift+Tab | Move between controls |
| Enter or Space | Open the focused tree row or graph node; press buttons |
| Escape | Close a dialog |
| F1 | Help for the focused control |

No action depends on hover, right-click or dragging.
