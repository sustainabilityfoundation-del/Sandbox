Maturities: idea, exploring, defined, evaluated, selected, engineering development, implemented,
verified, superseded, archived. Any change is allowed (Concepts may be reopened or developed
concurrently) except:

- entering selected, engineering development, implemented or verified needs a reviewer or administrator;
- superseding or archiving a Concept that is selected or later needs a reviewer or administrator;
- implemented needs an implementation with status implemented; verified needs verification status
  verified, which needs verified evidence.

**Implementation status** is derived from the implementations; **verification status** is set by a
reviewer with verified evidence. The **assessment** (AI collaboration page) is a deterministic checklist
that suggests a maturity and next steps; it never changes the Concept.
