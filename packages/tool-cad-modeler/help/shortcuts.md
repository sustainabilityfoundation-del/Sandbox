title: Keyboard shortcuts
kind: shortcuts
summary: Keys for undo and redo, view navigation and sketch selection.
keywords: [keyboard, shortcuts, keys, accessibility]
related: [cad-modeler.viewport]
---

| Keys | Action |
| --- | --- |
| Ctrl+Z / Ctrl+Y (Ctrl+Shift+Z) | Undo / redo (outside text fields) |
| Arrow keys (3D view focused) | Orbit |
| + / − | Zoom in / out |
| F | Fit the model |
| Escape | Clear the face selection |
| Tab, then Enter or Space (sketch) | Select a sketch entity |
| Arrow keys (sketch focused, drawing tool chosen) | Move the drawing cursor one grid step (Shift: five steps) |
| Home (drawing) | Cursor to the sketch origin |
| Enter or Space (drawing) | Place a point at the cursor |
| Escape (drawing) | Cancel the shape in progress, or leave the drawing tool |
| Enter / Escape (value fields) | Apply / discard the edit |
| F1 | Help for the focused control |
