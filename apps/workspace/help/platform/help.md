- **Help menu** (the **?** button in the header): Help Centre, contextual help, getting started,
  keyboard shortcuts, a submenu for each tool you can use, API documentation and version information.
- **F1** opens the topic for the focused control; if there is none, for the open tool or the selected
  object.
- **Help Centre** searches all available documentation. Results only include tools in your
  subscription.
- **Tutorials** highlight the controls step by step. Each tutorial also has a written version.
- **The assistant** reads the same documentation (operation `read_help`), but it acts only through the
  platform's operations, never because a help page describes something.

If a tool has no documentation yet, its submenu says so; this is shown as missing work, not hidden.
