**Settings** (gear icon beside the Help menu) opens the Settings centre. Search finds a setting on any
page; `?settings=<page>` in the address opens a page directly (for example `?settings=ai`).

| Page | Contents |
| --- | --- |
| Platform | Theme, density, service mode (API or demo), development user, demo subscription, layout and remembered windows. These are this browser's preferences; the header menus change the same values |
| AI and reasoning | Connect your AI account, choose the model, decide what the AI may access, data sharing, limits and the audit ([details](help:ai.policy)) |
| Module pages | Settings a module declares (for example filters, units or defaults); a module without settings has no page |

Settings stored on the server (AI and reasoning, module pages) are checked there: values out of range,
choices above a project limit, or a page changed meanwhile in another window are refused with an
explanation, and nothing is half-saved. Project limits can be changed only by a project administrator.
