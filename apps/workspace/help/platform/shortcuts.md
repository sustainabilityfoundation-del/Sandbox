| Keys | Action |
| --- | --- |
| Ctrl+K (Cmd+K) | Commands and tools |
| / | Focus search |
| F1 | Help for the focused control, the open tool or the selected object |
| Escape | Close the open menu, dialog or panel |
| Tab / Shift+Tab | Move between controls |
| Enter | Activate the focused control; send a ChatGPT message |
| Shift+Enter | New line in a ChatGPT message |

Single-key shortcuts never act while you are typing in a field or while a dialog is open. Tool
shortcuts are listed in each tool's help (Help menu → the tool → Keyboard shortcuts).
