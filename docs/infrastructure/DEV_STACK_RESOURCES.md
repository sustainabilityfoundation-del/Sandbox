# Dev stack: resources for owner approval

Status: **For approval**, 17 October 2026, aws-infrastructure agent (phase 2). **Nothing in this list exists in AWS.** The list comes from
`cdk synth` of `infra/aws` (offline; revision recorded in the commit that adds this file). Approve it, or ask for changes, before any
`cdk bootstrap` or `cdk deploy` ([runbook](DEPLOYMENT_RUNBOOK.md) part A). Decision record: [ADR-0088](../decisions/0088-aws-infrastructure-as-code-cdk.md).
Cost per resource: [AWS_COST_ESTIMATE.md](AWS_COST_ESTIMATE.md) (about USD 52 a month always on, about 41 with the optional night schedule).

Target: a **new member account** of the organization (not the management account), one region (default us-east-2). The account ID and
region are parameters (`-c account=... -c region=...` or the CLI profile); the code contains neither.

## 1. What you are approving, in plain terms

| Group | What is created | Billable? |
| --- | --- | --- |
| Network | One VPC (10.20.0.0/16) with two public and two isolated subnets in two zones, an internet gateway, an S3 gateway endpoint. **No NAT gateway, no interface endpoints.** Four security groups. | Public IPv4 address of the running task only |
| Database | RDS PostgreSQL 17, one instance (db.t4g.micro), single zone, 20 GB gp3 (grows to 100 GB), encrypted, 7 days of backups, deletion protection, final snapshot kept if removed, not reachable from the internet, TLS required. A generated master secret `ews/dev/db`. | Yes |
| Object store | One encrypted EFS file system with an access point, mounted at `/data/objects`; daily automatic backup. Retained if the stack is removed. | Yes (cents) |
| Secrets | `ews/dev/db` (database login) and `ews/dev/assistant-key` (64 hex characters, `EWS_ASSISTANT_KEY`), both generated by Secrets Manager and retained if the stack is removed. You never see or type them. | Yes (0.40 each) |
| Images | ECR repository `ews/api` (immutable tags, scan on push, last 20 images kept). | Yes (cents) |
| Backend | ECS cluster `ews-dev`; service `api` with **one** ARM64 Fargate task (0.5 vCPU, 1 GB) behind an **internal** load balancer; a one-off migration task definition `ews-dev-migrate`; log group `/ews/dev/api` (30 days). | Yes |
| Front door | One CloudFront distribution (HTTPS only): the static site from a private S3 bucket and `/api/*` from the backend over a private VPC origin. A CloudFront Function applies the **shared password gate** and sends `/` to `/workspace/`; its credential hash lives in a Key Value Store that starts empty (the gate answers 503 until you set it). | Within the free allowance at prototype traffic |
| GitHub access | An OpenID Connect identity provider and the role `ews-gh-deploy-dev`, trusted for one repository and one branch only (no access keys). | No |
| Optional | A night schedule (`-c nightSchedule=true`) that stops the task at 20:00 and starts it at 07:00 on weekdays. Off by default. | Saves about 11 a month |

Created automatically by AWS on first use, not by this stack: service-linked roles for ECS, Elastic Load Balancing, RDS and CloudFront
VPC origins (no cost). `cdk bootstrap` (once per account and region) adds its own small set: an S3 bucket for deployment files, an ECR
repository for CDK assets, an SSM parameter and five IAM roles (cost: cents).

Not included (decisions or later work): CloudWatch alarms and the alarm e-mail, AWS Budgets, a custom domain and certificate, WAF,
production stacks, Cognito sign-in, S3 adapters for blobs.
